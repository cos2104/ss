# 빛의 중첩과 간섭 시뮬레이션

비상교육 고등 『물리학』 **III. 빛과 물질 › 1. 빛의 이해 › 01. 빛의 중첩과 간섭**
(교과서 124~129쪽)에 맞춘 3D 시뮬레이션입니다.

## 실행

`index.html` 을 브라우저로 열면 됩니다. (Babylon.js 를 CDN 에서 받으므로 인터넷 연결 필요)

로컬 서버로 띄우려면 상위 폴더에서:

```
node devserver.js      # http://localhost:8765
```

## 흐름

**실험 메뉴 → 준비물 배치 → 실험 진행** 의 3단계입니다.

준비 단계에서는 실험대 위에 점선으로 자리가 표시됩니다. 아래 «실험도구» 트레이에서
도구를 끌어다 해당 자리에 놓으면 배치되고, 엉뚱한 곳에 놓으면 어디에 놓아야 하는지
알려 줍니다. 모두 놓으면 자동으로 실험 단계로 넘어갑니다.
(수업 시간이 촉박하면 «자동 배치» 버튼으로 건너뛸 수 있습니다.)

## 물리 계산

무늬를 미리 그려 둔 그림으로 바꿔 끼우는 방식이 아니라 매번 실제로 계산합니다.
모든 식은 `js/physics.js` 에 있습니다.

**음파의 간섭** — 근사식이 아니라 실제 거리로 경로차를 구합니다.

```
Δ = |√((x+d/2)² + L²) − √((x−d/2)² + L²)|
I = cos²(πΔ/λ)          λ = v/f,  v = 331.5 + 0.6t  (20 ℃ 에서 343.5 m/s)
```

그래서 스피커가 가까울 때 첫 보강 지점이 근사식 <i>λL/d</i> 와 어긋나는 것까지
그대로 드러납니다 (1000 Hz · <i>d</i>=1 m · <i>L</i>=1 m 에서 실제 40.4 cm, 근사식 34.4 cm).

**이중 슬릿** — 간섭항에 단일 슬릿 회절 포락선을 곱합니다.

```
Δx = λL / d
I(y) = cos²(π d y / λL) · sinc²(π a y / λL)
```

**단일 슬릿**

```
a sinθ = mλ   (어두운 무늬)
w = 2λL / a   (중앙 밝은 무늬의 폭)
```

파장 400~700 nm 는 실제 보이는 색으로 변환해 스크린에 칠합니다.

조절 범위는 실제 실험값을 따릅니다. <i>d</i> = 0.10~0.60 mm, <i>L</i> = 0.5~2.0 m,
이중 슬릿의 <i>a</i> 는 두 슬릿이 겹치지 않도록 <i>d</i>/2 로 상한이 자동으로 걸립니다.

## 파일

```
index.html                 화면 구조
css/style.css              스타일
assets/icons/              사이드바 아이콘
js/physics.js              간섭·회절·음파 계산, 파장→색 변환
js/lab-content.js          학습 패널 내용, 실험도구 아이콘
js/scene-sound.js          실험 1 — 음파 간섭
js/scene-doubleslit.js     실험 2 — 이중 슬릿
js/scene-singleslit.js     실험 3 — 단일 슬릿
js/main.js                 메뉴·단계 전환·끌어다 놓기·패널·퀴즈
```

새 실험을 붙이려면 scene 모듈에 `create / update / placeTool / dropAt /
controlsHTML / bindControls / readoutHTML / drawGraph` 를 갖추고
`main.js` 의 `EXPS` 에 등록하면 됩니다.
