# 고등 물리 교과서 시뮬레이션

비상교육 고등 『물리학』 · 『역학과 에너지』 · 『전자기와 양자』 세 교과서의
**핵심 탐구**·**해 보기** 활동을 그대로 실행해 볼 수 있는 3D 시뮬레이션 모음입니다.

전체 **35종** — 물리학 18종 + 역학과 에너지 9종 + 전자기와 양자 8종.
새 교과서의 시뮬레이션은 상황에 맞는 유형으로 만들었습니다:
**① 시공간 초월형 · ② 인터랙티브 스토리텔링형 · ③ 체험·조작 게임형 ·
④ 문제해결형 · ⑤ 샌드박스형 · ⑥ 데이터 기반 실험형**

## 실행

`index.html` 을 브라우저로 열면 전체 목록이 나옵니다.
(Babylon.js 를 CDN 에서 받으므로 인터넷 연결 필요)

로컬 서버로 띄우려면:

```bash
node devserver.js
```

`http://localhost:8765` 로 접속합니다.

## 공통 흐름

모든 시뮬레이션이 같은 구조입니다.

**준비물 배치 → 실험 진행**

준비 단계에서는 실험대에 점선으로 자리가 표시됩니다. 아래 «실험도구» 트레이에서 도구를
끌어다 해당 자리에 놓으면 배치되고, 엉뚱한 곳에 놓으면 어디에 놓아야 하는지 알려 줍니다.
모두 놓으면 자동으로 실험 단계로 넘어갑니다. 시간이 촉박하면 «자동 배치» 로 건너뛸 수 있습니다.

오른쪽 사이드바에 **도움말 · 학습목표 · 사전학습 · 실험실 안전 · 핵심정리 · 퀴즈**와
**실험 다시하기 · 실험 목록**이 있습니다. 도움말은 시뮬레이션마다 내용이 다릅니다.

실험 단계에 들어가면 왼쪽 아래에 **«탐구 수행» 패널**이 나타나 교과서의 실험 순서를
한 단계씩 안내합니다. «다음»을 누르며 진행하고, 마친 단계에는 체크가 붙습니다.
(공용 셸 시뮬레이션은 `content.js` 끝 `LabContent.steps`, `sim/` 은 `main.js` 의 `STEPS`)

화면 오른쪽 아래 **기록표**는 교과서의 결과표와 같은 형태입니다. 조건을 바꿔 가며 «기록» 을
누르면 값이 쌓여 학생이 표를 채우듯 쓸 수 있습니다.

## 물리 계산

값과 무늬는 미리 만들어 둔 그림이 아니라 **매번 실제로 계산**합니다.

| 시뮬레이션 | 핵심 식 |
|---|---|
| 돌림힘 | `τ = F × r`, 지레의 평형 `w×a = F×b` |
| 운동 | `F = ma`, `v = at`, `s = ½at²` |
| 충돌 | 운동량 보존 + 반발계수 `e` 로 탄성/비탄성/완전비탄성을 한 식으로 |
| 에너지 | `Ep = mgh`, `Ek = ½mv²`, 공기 저항은 속력 제곱에 비례 |
| 열 전환 | `W = Nmgh = cmΔT` → `ΔT = Ngh/c` (질량이 약분된다) |
| 열기관 | `e = W/Q₁ = 1 − Q₂/Q₁`, 카르노 `e_max = 1 − T₂/T₁` |
| 전기장 | `F = kq₁q₂/r²`, `E = kQ/r²`, `V = kQ/r` |
| 회로 | `V = IR`, 직렬 `R = R₁+R₂` / 병렬 `1/R = 1/R₁+1/R₂`, `P = VI` |
| 축전기 | `Q = CV`, `U = ½CV²`, `τ = RC`, 충전 `V = V₀(1−e^(−t/τ))` |
| 자성 | 자기 구역 정렬 모형 (강자성만 잔류 자기) |
| 전류 자기장 | `B = μ₀I/(2πr)`, 오른손 법칙 |
| 유도 | `ε = −N dΦ/dt`, 자기 선속은 축상 쌍극자 근사 |
| 간섭 | `Δx = λL/d`, `I = cos²(πdy/λL)·sinc²(πay/λL)` |
| 렌즈 | `1/a + 1/b = 1/f`, `m = −b/a` (부호로 실상·허상, 정립·도립 판정) |
| 광전 효과 | `E = hf = hc/λ`, `Ek(max) = hf − W` |
| 스펙트럼 | `Eₙ = −13.6/n² eV`, `λ = hc/ΔE` |
| 반도체 | 볼츠만 인자 `exp(−Eg/2kT)`, 도핑 운반자 |
| 상대성 | `γ = 1/√(1−β²)`, `Δt = γΔt₀`, `L = L₀/γ` |
| 포물선 | `vx = v₀cosθ`, `vy = v₀sinθ − gt`, `R = v₀²sin2θ/g` |
| 원운동 | `F = mv²/r = mrω² = 4π²mr/T²` |
| 궤도 | 중력 수치적분(벨로시티 베를레), `T² = a³`, `vₑ = √(2GM/R)` |
| 일반 상대성 | 체중계 `N = m(g+a)`, GPS +38 μs/일 |
| 기체 | `PV = nRT`, `Q = ΔU + W`, 단열 `TV^(γ−1) = 일정` |
| 엔트로피 | `W = C(N,n)`, `S = k lnW`, `ΔS = Q(1/T_L − 1/T_H)` |
| 단진동·파동 | `T = 2π√(m/k)`, `a = −ω²x`, `v = fλ` |
| 도플러 | `f′ = f₀(v±v_O)/(v∓v_S)`, 반사파는 두 번 적용 |
| 정상파 | 현·열린 관 `f = nv/2L`, 닫힌 관 `f = nv/4L (홀수)`, `v = 2f(y₂−y₁)` |
| 로런츠 힘 | `r = mv/qB`, `T = 2πm/qB` (속도 회전으로 정확 적분) |
| 편광 | 말뤼스 `I = I₁cos²Δθ` |
| 물질파 | `λ = h/mv`, 확률 `cos²(πdy/λL)·sinc²`, 기각법 표본 추출 |
| 터널 | 직사각형 장벽 정확식 `T = 1/(1+V₀²sinh²(κw)/4E(V₀−E))` |
| 원자 | 1s 오비탈 `P(r) ∝ r²e^(−2r/a₀)` (감마 분포 표본) |
| 별빛 | 질량 결손 `E = Δmc²`, 원소별 실제 방출선 파장 |

### 검증한 값

브라우저에서 직접 실행해 확인했습니다. 17개 페이지 모두 콘솔 에러 0건.

- **돌림힘** — 교과서 실험 ①②③(1×4=2×2, 2×3=3×2, 4×2=2×4) 모두 평형 판정

- **충돌** — 등질량 탄성: A 정지·B 가 속도 전부 / 완전비탄성: 각각 절반, 손실 50 %
- **에너지** — 5 m 낙하 착지 9.90 m/s, **질량과 무관**. 공기 저항 시 26.39 + 22.61 = 49.00 J
- **진자** — 8 초 동안 역학적 에너지 2.94 J 로 일정(드리프트 ±0.001).
  최저점 속력 5.42 m/s = √(2<i>gh</i>), 반대쪽에서 정확히 같은 각도(±60°)까지 올라감.
  감쇠를 켜면 진폭이 60° → 22° 로 감소
- **열 전환** — 200 회에 +0.98 ℃. **모래를 2배로 넣어도 그대로**, 높이 절반이면 0.49 ℃

- **전기장** — `E`=28125 N/C, `V`=22500 V 이론값 일치. 같은 부호 중간 `E`=0, 다른 부호 중간 `V`=0

- **정상파** — 닫힌 관 홀수 배진동만, 공명 19.5/58.5/97.4 cm → 음속 측정 343.2 m/s
- **정전기** — 4단계 유도 대전, 풍선 (+)(−) 어느 쪽이든 물줄기가 같은 쪽으로 휨
- **로런츠** — r=3/T=6.28, v 2배→r만 2배, B 2배→r·T 절반, 사이클로트론 0.8→4.1 가속 후 방출
- **편광** — 말뤼스 50/25/0 %, LCD cos² 변화 vs OLED 일정, 물 반사광 수평 편광
- **레이저** — 준안정 없으면 펌핑 100%에도 반전 불가(50% 상한), 발진 시 광자 65개로 증폭
- **물질파** — 전자 3200개: 상쇄점 0개/중앙 88개, 관측 켜면 두 줄(슬릿 위치 봉우리)로 전환
- **터널** — T=2.5%(E=5,V₀=10,w=0.8), 두께 절반 → 27.3% (11배), 100발 중 3발 통과,
  STM 전류 0.1 nm 당 1.76배
- **원자** — 전자구름 700점의 봉우리 2.28 ≈ a₀ 2.4, 평균 r = 3.56 ≈ 1.5a₀, Δx·Δp = 0.25 불변
- **별빛** — 흡수선-방출선 대조 정답/오답 판정, 질량 결손 0.0305 u → 28.4 MeV

## 폴더 구조

```
index.html              전체 목록 (허브)
devserver.js            개발용 정적 서버
common/
  lab.css               공용 스타일
  lab-shell.js          공용 셸 — 배치·사이드바·퀴즈·그래프·기록표
  lab-icons.js          실험도구 SVG 아이콘
  icons/                사이드바 아이콘 (원본 시뮬레이션에서 가져온 것)
<시뮬레이션>/           물리학: torque, motion, collision, energy, heat, engine,
  index.html                    efield, circuit, capacitor, magnetism, ampere,
  js/scene.js                   induction, lens, photoelectric, spectrum,
  js/content.js                 semiconductor, relativity
                        역학과 에너지: projectile, circular, orbit, genrel,
                                      gas, entropy, springwave, doppler, standing
                        전자기와 양자: electrostatic, lorentz, polarization, laser,
                                      matterwave, tunnel, atom, starlight
```

각 시뮬레이션 폴더는 세 파일뿐입니다.

- `index.html` — `Lab.boot({...})` 한 줄
- `js/scene.js` — 3D 장면 + 물리 계산 + 컨트롤
- `js/content.js` — 학습 패널 내용 + 퀴즈

## 새 시뮬레이션 추가하기

`js/scene.js` 에 아래를 갖춘 모듈을 만들고 `index.html` 에서 `Lab.boot` 에 넘기면 됩니다.

```js
{
  id, title, guide, prepGuide, tools: [{id, label, icon}],
  create(engine, canvas), update(), resetCamera(),
  placeTool(id), resetTools(), allPlaced(), dropAt(id, point), slotName(id),
  controlsHTML(), bindControls(root, onChange), readoutHTML(),
  graphTitle, drawGraph(ctx, W, H), graphFootHTML(),

  // 선택
  tick(dt)          // 애니메이션. true 를 돌려주면 측정값·그래프를 다시 그린다
  recordColumns[]   // 기록표 머리글 (있으면 기록표가 나타난다)
  recordRow()       // 한 줄 또는 여러 줄(배열의 배열)
  onEnterRun()      // 실험 단계로 들어갈 때
}
```

컨트롤 마크업은 `LabUI.slider()` / `LabUI.opts()` 로 만들고
`LabUI.bindSlider()` / `LabUI.bindOpts()` 로 상태에 묶습니다.
